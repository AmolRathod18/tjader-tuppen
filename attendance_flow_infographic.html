📌 Key System Rules
📍
Location-on-Action OnlyGPS is captured only when the employee manually clicks Check-In or Check-Out. No continuous background tracking.
📏
Radius VerificationDefault allowed radius: 200 metres from project coordinates. Configurable per project by admin.
🗄️
Data Saved on SuccessEmployee ID, Project, Check-In time, Distance, and Verification Status are persisted to the database.
🚩
Flagging SystemFailed verifications are flagged in the admin panel with full details for manual review.
🔒
Privacy-First DesignLocation data is used only for attendance verification and is never stored beyond what is necessary.
